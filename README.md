# MS Lava Rápido

Site institucional desenvolvido para a empresa MS Lava Rápido, especializada em lavagem automotiva em Teixeira de Freitas - BA.

## Funcionalidades

* Apresentação dos serviços
* Agendamento online
* Informações de contato
* Integração com WhatsApp
* Avaliações de clientes
* Design responsivo
* Interface moderna

## Objetivo

Oferecer uma presença digital profissional para a empresa, facilitando o agendamento de serviços e a comunicação com os clientes.
